# HairMirror V0.3：AI Hair Consultation 验证 MVP

## 1. 结论与范围

新定位合理：价值从“生成图片”转为“帮助客户和发型师做发型决策”。V0.3 以 Salon-first 验证为主，消费者仅保留轻量体验入口。目标不是本轮收费，而是验证发型师是否在真实咨询中持续使用并愿意进入付费试点。

### P0

- `REQ-001` 角色入口：用户选择 Consumer 或 Stylist；未授权访问受限操作必须进入登录。
- `REQ-002` 照片输入：支持一张正脸照片；校验大小、格式、单人、清晰度与无遮挡；失败时给可修复提示。
- `REQ-003` AI 分析：返回严格 JSON：`face_shape`、`head_shape`、`hair_type`、`current_traits`、`confidence`、`limitations`；允许 unknown，不做身份或医疗推断。
- `REQ-004` AI 推荐：固定最多 3 个方案；每项含 `style_name`、`why_fit`、`maintenance_minutes`、`execution_notes`；低置信度时说明需要发型师确认。
- `REQ-005` 咨询记录：Stylist 创建咨询，关联租户、创建人、原图、分析、推荐、生成资产、选中方案和状态。
- `REQ-006` 效果生成：复用现有生成队列；每个方案独立状态；部分失败不阻塞报告、沟通卡和重试。
- `REQ-007` 沟通卡：生成可复制的结构化文本，包含目标发型、两侧、顶部、纹理、打理目标与发型师确认项。
- `REQ-008` Salon 访问：同一 `salon_id` 的 Stylist 可访问记录；Consumer 只能查看被明确分享的记录；默认拒绝跨租户访问。
- `REQ-009` 咨询历史：按日期和状态列出咨询，可进入详情、删除；原图和生成资产遵循 30 天保留与删除策略。
- `REQ-010` 收费暂停：Paddle、次数包和付费 CTA 由 feature flag 隐藏；底层接口保留，不影响现有账单数据。

### P1

- `REQ-011` 侧脸照片；`REQ-012` 客户分享链接；`REQ-013` 二维码入口；`REQ-014` PNG/PDF 沟通卡导出；`REQ-015` 多员工角色和 Salon 管理。

### P2 / 明确不做

CRM、预约、POS、库存、门店经营报表、自动收费发布、几十种发型手动筛选、多角度全量生成。

## 2. 验证目标与口径

验证窗：30 天；样本：20 家合格 Salon，至少 10 家完成激活。激活定义为注册后完成 ≥3 次完整咨询；“每周 5+ 次”定义为激活 Salon 中每周完成咨询总数 ≥5。商业信号定义为至少 3 家签署付费试点或完成真实付费意向，不把口头好评当付款意愿。

- `GOAL-001` 20 家合格 Salon 注册。
- `GOAL-002` ≥10 家激活，激活率 ≥50%。
- `GOAL-003` 激活 Salon 每周完成咨询 ≥5 次。
- `GOAL-004` ≥3 家进入付费试点。
- `GOAL-005` Consumer 上传率 ≥50%，生成完成率 ≥70%，分享率仅作为观察指标（P1 未开发时不作为放行条件）。
- `GOAL-006` 结构化分析 p95 ≤10 秒；完整咨询（不含排队）p95 ≤180 秒；失败任务必须可见、可重试且不扣除有效权益。

## 3. 用户故事与验收

- `US-001` 作为 Stylist，我能新建咨询并看到可解释的 3 个推荐。验收：创建人、租户和时间均持久化；刷新后结果一致。
- `US-002` 作为 Stylist，我能把执行建议复制给客户或同行。验收：沟通卡字段齐全、无空白占位符、复制成功有反馈。
- `US-003` 作为 Consumer，我能在登录后完成一次完整体验。验收：上传、分析、推荐、生成、查看、删除全链路可完成。
- `US-004` 作为用户，我能理解失败原因并恢复。验收：每类错误都有人类可读原因和重试/重新上传动作。
- `US-005` 作为 Salon 管理者，我不能看到其他 Salon 的照片或记录。验收：API 和页面均返回 403/404，不泄露资源存在性。

## 4. AI 与安全约束

模型输出必须通过 schema 校验；缺失、越界或非 JSON 进入 fallback，并记录非 PII 的错误码。分析结果必须展示“AI 建议，最终由专业发型师确认”。照片需取得处理同意，默认不用于训练；30 天自动清理，用户可立即删除。日志、分析埋点和错误上报不得包含原图、邮箱或可识别照片 URL。

## 5. 非功能与上线门槛

必须支持重复提交幂等、任务取消/重试、生成部分失败、数据库迁移回滚；桌面和 375px 移动宽度无横向滚动。放行条件：`npm run check`、相关 Vitest、E2E 与权限/隐私测试通过；无 P0/P1 未关闭缺陷；免费额度和收费开关状态可回滚。
