# HairMirror V0.3 验收记录

版本：V0.3
日期：2026-08-09
范围：P0 咨询流程、沟通卡、Salon 咨询记录、生成队列关联、隐私与权限、可配置咨询模型适配器。

## 结论

P0 咨询链路已完成本地可验收闭环，可进入受控 Salon/Consumer 试用。链路为：角色入口 → 照片授权与质量校验 → 创建咨询 → 分析 → 推荐 → 三个持久化生成任务 → 结果图片 → 失败/重试/取消 → 选择方向与沟通卡 → 历史详情/删除。默认模型为本地演示模型；配置 `CONSULTATION_PROVIDER_URL` 后才调用外部分析服务，外部生成模型仍需在目标环境单独验收。暂不作为开放式消费者产品发布。

## 已完成

- Consumer / Stylist / Salon 角色隔离及 Salon 咨询入口。
- Consumer 与 Salon 共用同一咨询核心流程；个人咨询自动归属本人，Salon 可用已有个人账号邮箱关联客户记录。
- 新建咨询必须确认照片使用授权，并确认照片为单人、正面、清晰；服务端额外校验图片签名、大小和 512×512–8000×8000 像素范围。
- `POST /api/consultations`、`PATCH /api/consultations/:id` 的分析、归档、选择方案流程。
- 可持久化的分析报告、推荐方案、选中方案和沟通卡。
- 未配置外部模型时的确定性安全回退，并记录 `source`、`status`、`reason`。
- 可选 HTTP 咨询模型适配器，支持 Bearer 密钥、超时边界和失败回退。
- 咨询历史留存、删除/归档、隐私边界及生成队列关联。
- 每个推荐方案独立生成任务，任务状态可通过咨询详情读取，支持 `generate`、`retry`、`cancel`。
- 生成完成后回写 `recommendations.image_url`，咨询页和历史详情页均展示结果图片及失败/排队/取消状态。
- 三个推荐任务共享一次咨询级权益预留；重复生成请求保持任务和权益幂等，全部成功消费一次，全部失败/取消释放一次，部分成功不重复扣费。
- 原图清理改为引用感知：咨询保留期、其他队列任务和删除流程均不会提前删除共享源图。
- 删除或到期清理咨询时，关联的排队任务会取消，已完成结果资产会清理，处理中的任务交由 worker 完成取消。
- 同 Salon 成员及关联消费者可读取其有权访问的生成资产，跨租户仍返回未找到。
- 结果图片缺失会进入明确失败态，不会写成成功；咨询级状态持久化为 queued / processing / partial / completed / failed / cancelled。
- 暂不开放正式支付，符合当前 PRD“先验证场景、暂停商业化收费”的策略。

## 咨询模型配置

- `CONSULTATION_PROVIDER_URL`：可选，外部分析服务地址。
- `CONSULTATION_PROVIDER_API_KEY`：可选，服务端 Bearer 密钥。
- `CONSULTATION_PROVIDER_TIMEOUT_MS`：可选，默认 20000；允许范围 1000–120000。
- 请求体发送 `{ imageId, imageDataUrl, role }`；原图只从服务端临时存储读取并按留存策略清理。
- 响应支持 `{ report }`、`{ data: { report } }` 或直接返回报告对象。

## 已知边界

- 外部分析服务需要能接收并处理 `imageDataUrl`；真实模型的照片质量、响应延迟和推荐质量仍需用目标服务的黄金样本回归。
- 自动识别多人、遮挡和脸部数量不是本地规则引擎能力，当前由创建者确认并由外部分析模型承担进一步判断；这不是公开发布质量门槛的替代品。
- P1 的侧脸上传、分享链接、二维码入口和更细的账号权限 UI，以及 P2 CRM、POS、多员工管理均按 PRD 延后。
- 支付和开放式消费者发布继续延后。

## 对抗式复核

- 未配置、配置非法或外部 HTTP 失败时，均回退到确定性报告并返回可恢复状态；未配置时不会发出外部请求。
- 外部地址仅允许 HTTP(S)，超时值会被限制在安全范围内。
- API 路由要求登录并执行租户/角色校验；沟通卡和历史记录只返回当前账号有权访问的数据。
- 删除和归档路径遵守现有留存策略，不暴露原始图片路径。
- 公共咨询 DTO 和生成任务 DTO 不返回 `sourcePhotoPath`、`source_image_path` 或本地资产路径。
- 跨租户咨询、推荐方案和生成资产均执行 Salon/消费者归属校验；结果资产不会仅因拥有任务 ID 而跨租户读取。
- 重复 `generate` 只返回既有任务，不新增 `generation_jobs` 或 `generation_access_charges`。
- 无 active model 时生成入口返回 `503 MODEL_UNAVAILABLE`，不会创建任务或静默成功。
- Consumer 不能读取未绑定的 Salon 咨询；Salon 不能读取无本店租户归属的 Consumer 咨询；邮箱关联后双方仅能读取该条记录。
- 低清或二进制签名异常的照片不会落库；缺失授权不会写入咨询记录。
- 全量生成任务入队在一个数据库事务内完成，无法出现“只入队两张图但已扣三图权益”的半成品。
- 共享源图在任一推荐任务完成或取消后仍保留；咨询删除且无其他任务引用后才清理。
- 删除咨询不会留下继续运行的排队生成任务；处理中的任务仅保留到 worker 完成取消。
- 375px 视口无横向滚动；收费入口保持由既有 feature flag 控制，未新增付费 CTA。
- 计费流程保持停用/延后，没有新增误扣费路径。

## 尚未关闭的环境边界

- RunningHub/外部生成服务需要安全环境中的有效模型配置、凭据和真实照片回归；本轮验证本地演示生成、持久化接口和失败补偿。
- 本地只做像素/签名/大小校验，单人、正面、无遮挡由创建者确认；公开测试前仍需接入或验证图像质量模型及黄金样本阈值。
- 未执行登录后的真实浏览器上传与外部模型长任务回归；当前由 API 集成测试、队列反例测试、构建和本地浏览器入口/鉴权冒烟覆盖。
