# 年轻成人发型测试候选集

## 范围

- 目标年龄：18—35岁成年人。
- 内部模型测试用途，不用于产品宣传、人物背书或公开案例。
- 来源：Pexels可追溯下载链接，使用时遵守Pexels许可条款。
- 不进行身份识别，仅评估发型编辑后的人物一致性。

## 已完成筛选

18张候选中通过9张：女性4张、男性5张。排除原因包括手部遮挡、侧脸、低照度、商业美容构图和面部像素不足。第二批补充了男性中长卷发和中长直发场景。

当前9张只用于小规模预检，尚不足以构成最终30张评测集。下一批优先补充：女性短发、女性自然卷发、细软发、自然发际线偏高以及更多肤色场景。

## 评估分层

- A层：正脸、光线均匀、头发无遮挡，用于身份一致性和发型可辨识性主评测。
- B层：眼镜、卷发、中长发等边界场景，用于发现模型稳定性问题。
- 不入集：手部遮挡、明显侧脸、暗光、面部像素不足或成年状态不可判断。

## 使用规则

1. 原图和生成结果不进入营销素材。
2. 每张图保留来源URL、筛选结论和测试用途。
3. 测试结束后删除本地原图及生成结果。
4. 若许可条款、来源或成年状态存在疑问，立即排除。
