# 发布判断

更新日期：2026-07-16

## 本地演示：GO

- 用户流程、账号、运营台和模型配置可运行；
- 任务、方案、选择、反馈和生成结果可持久化；
- 自动化测试、类型检查、代码检查和生产构建通过。

## 单机受控内测：GO

- 固定游客身份、日额度、任务总量和全局费用熔断已启用；
- 生成队列支持重启恢复、重试、幂等、取消和失败补偿；
- 真实删除、30 天清理、隐私协议、健康检查、告警、备份和回滚已实现；
- 测试数据库、原图和生成图片使用独立临时目录。

部署前必须配置运营密钥、内部任务密钥、模型密钥主密钥、告警 Webhook 和独立备份目录，并实际完成一次告警与恢复演练。

## 公开测试：NO-GO

- 尚未完成多人物真人黄金样本评测和明确质量门槛；
- 当前 SQLite 与本地文件适合单机，不支持多实例公开服务；
- 正式域名、HTTPS、异地备份和事故值班责任尚未验证。
- Gumroad 公开购买链接已配置，真实订单的购买、激活、取消和退款尚未演练。

## 付费商用：NO-GO

Gumroad License Key 订阅代码闭环和公开购买链接已经完成，但公开商用前仍必须配置生产加密密钥，完成真实购买、取消、退款与争议演练，并迁移至托管数据库和私有对象存储，完成容量测试、数据迁移演练、跨账号媒体访问测试和供应商 SLA 验证。服务条款和隐私政策还需补入实际经营主体、支持邮箱、退款规则与隐私联系渠道。
