# SEO 与 GEO 上线规范

## 目标

公开页面可被搜索引擎抓取、理解和收录；搜索引擎与 AI 搜索能够从站内公开来源准确引用产品功能、价格、额度、照片保存期限和效果边界。

## 已实现

- 全站标题模板、描述、Canonical、Open Graph、Twitter Card 和大图预览
- `robots.txt`：开放公开页面，屏蔽账号、管理、接口、账单和登录路径
- `sitemap.xml`：仅收录首页、价格、常见问题、隐私政策和服务条款
- 首页 `WebApplication` 结构化数据
- 常见问题页 `FAQPage` 结构化数据，内容与页面可见文本一致
- `llms.txt` 与 `llms-full.txt`：提供可核验的产品事实和权威页面入口
- 登录、账号和后台页面设置 `noindex`

## 发布后操作

1. 绑定长期使用的品牌域名，并同步修改 `PUBLIC_APP_URL`。
2. 在 Google Search Console 和 Bing Webmaster Tools 验证域名。
3. 提交 `/sitemap.xml`，检查首页、价格页和常见问题页的抓取与规范网址。
4. 监控展示量、点击率、查询词、收录状态和富媒体结果错误。
5. 产品价格、额度、保存期限或支付方式变化时，同步修改页面、结构化数据和两个 `llms` 文件。

## 边界

技术优化只能提高抓取和理解质量，不能保证排名。不得添加虚假评价、评分、销量、专家背书或与页面不可见内容不一致的结构化数据。
