# Architecture

发型镜是 Next.js App Router 应用。浏览器读取用户照片并提交 Base64 Data URI 和结构化偏好。服务端校验输入，规则引擎选择三个发型模板，再由当前启用的生成提供方返回结果。RunningHub 模式会把原图发送给 RunningHub；生成结果下载到受权限保护的本地资产目录。

## Flow

浏览器上传预览 → 文件类型、签名和大小检查 → `/api/design-tasks` → 限流、额度与费用熔断 → SQLite 持久化队列 → 独立 Worker → 生成提供方 → 私有资产存储 → 结果渲染。

`demo-fixed` 只返回固定演示结果；RunningHub 已实现真人图生图。任务由持久化队列和独立 Worker 执行，支持幂等、自动重试、取消、心跳恢复和失败补偿。

## 账号与数据

- 本地后端使用 SQLite，数据文件默认位于 `data/hairstyle.db`。
- 账号角色为个人用户、门店管理员和门店员工。海外用户默认使用邮箱登录；历史中国手机号账号继续兼容。员工账号只能由所属门店管理员创建。
- 密码使用 `scrypt` 加盐哈希；服务端只保存会话令牌的 SHA-256 哈希。
- 登录态使用 HttpOnly、SameSite Cookie，并对注册和登录尝试限流。
- 已登录用户的生成用量、任务和结果写入 SQLite；游客任务归属于 HttpOnly 会话。
- SQLite 使用在线备份 API 创建一致性快照，并与生成资产共同生成校验清单。多实例或高并发部署应迁移至 PostgreSQL 与私有对象存储。

## 国际化与支付

- 用户端默认英文，通过语言 Cookie 切换简体中文；运营台保持中文。
- 美国和东南亚市场统一按 USD 结算，不做本地币种换算。
- Gumroad Checkout 承担支付信息采集，应用不保存完整银行卡信息。
- Gumroad 商品是价格和账期来源，应用只接受配置中的 USD Membership。
- 订阅权益由服务端 License API 验证结果更新，浏览器不能自行发放额度。
- License Key 使用 AES-256-GCM 加密保存，不可逆指纹和 Subscription ID 防止跨账号重复绑定。
- 生成前按周期复核订阅，维护任务补充复核；外部故障宽限最多 72 小时。
- Stripe Checkout、Webhook 和 Customer Portal 代码保留为单一备用通道。

## 模型运营

- 模型配置包含供应商、模型、接口地址、优先级、超时、启停状态和每张成本。
- API 密钥使用 AES-256-GCM 加密，接口和管理界面只返回脱敏尾号。生产环境必须配置 `MODEL_SECRET_KEY`。
- 生成任务状态为排队、处理、完成、失败或取消，并记录尝试次数、错误码、预估成本和实际成本。
- 游客使用 30 天固定 HttpOnly 会话标识；请求频率、个人日额度、平台任务上限和平台费用上限均持久化。
- 全局费用熔断同时计算已完成实际费用和排队、处理中任务的承诺费用，避免并发透支。
- 用户额度按月计算：个人用户 30 张、员工 100 张、门店管理员 500 张。入队时原子预留，完成后转为已用，失败时释放。
- 运营管理员可调整单个用户的当月额度，但不能低于已使用与预留数量。
- 额度与模型配置变更写入 `audit_logs`，业务更新和审计记录使用同一数据库事务。
- 未实现的外部供应商不会回退为本地图片冒充结果，任务会失败并记录明确错误。

### RunningHub

- 适配器使用 `rhart-image-n-g31-flash-lite/image-to-image` 提交图生图任务，通过 `/openapi/v2/query` 轮询结果。
- 三个发型方案并行提交，每项使用独立的人物一致性约束提示词。
- 提交时使用 Base64 Data URI 传递原图，不向浏览器暴露供应商密钥。
- RunningHub 结果链接只有 24 小时有效期。服务端在任务完成后立即下载并转存，用户通过受权限保护的资产接口访问。
- 本地版保存在 `data/generated`；生产版需替换为私有对象存储。

## 数据留存与可靠性

- 用户方案、结果、选择和反馈均写入 SQLite。
- 临时原图成功或取消后立即删除，失败重试最长保留 24 小时；任务与结果默认保留 30 天。
- 维护任务处理到期删除、僵死任务恢复、告警评估和计划备份。
- `/api/health` 提供无敏感信息的健康指标；详细队列、告警、事件和备份仅在运营台可见。
- 告警通知失败与事件记录失败均与核心生成事务隔离。

## Trust boundaries

- 浏览器不持有模型密钥。
- API 对所有输入做服务端校验。
- 运营台只读取脱敏任务元数据，不读取照片。
- 运营台使用环境密钥和 HTTP-only Cookie；任务变更按登录用户或游客会话校验所有权。
- 本地图片存储仅用于开发和受控内测；生产必须替换为私有对象存储。
